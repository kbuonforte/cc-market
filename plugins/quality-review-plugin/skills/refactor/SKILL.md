Review the selected code or current file and suggest concrete refactoring improvements.

- Identify duplication, overly complex logic, or poor naming
- Suggest smaller, more focused functions where appropriate
- Prefer simple, readable solutions over clever ones
- Only suggest changes that improve clarity or maintainability — not stylistic preferences

Output the refactored code with a brief note for each change explaining why.
